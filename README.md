# Neuronest — Developer Readiness Test

## Purpose

This is a safe practice and assessment repository for the Neuronest development team.

**⚠️ IMPORTANT: This is NOT the actual Neuronest application repository.**

The purpose of this assessment is to understand whether team members are comfortable with:
- Git/GitHub workflow
- JavaScript fundamentals  
- React/Expo fundamentals
- Development workflow
- Independent learning and troubleshooting

## Assessment Guidelines

### Individual Work
- This test is **individual** — complete it on your own
- You **may** use documentation, Google, ChatGPT, tutorials, etc.
- You **should not** copy another participant's answers
- Not knowing something is completely acceptable
- The purpose is to identify learning gaps, not to embarrass anyone

### Git Workflow

You **must** follow this exact workflow:

```
clone
  ↓
create branch
  ↓
make changes
  ↓
git add
  ↓
git commit
  ↓
git push
  ↓
open Pull Request
  ↓
request review
```

### Branch Naming

Use this format: `yourname-week1-test`

**Examples:**
- `john-week1-test`
- `sarah-week1-test`
- `alex-week1-test`

### ⚠️ Critical Rules

1. **DO NOT** work directly on `main`
2. **DO NOT** merge your own Pull Request
3. **DO** create a branch for your work
4. **DO** open a Pull Request when ready for review

## Getting Started

1. Clone this repository to your local machine
2. Read `ASSESSMENT.md` for the complete test instructions
3. Create your branch using the naming convention above
4. Complete the assessment tasks
5. Open a Pull Request for review

## Questions?

If you're blocked or confused about something, that's normal! Document your questions in your assessment responses.

Good luck! 🚀
